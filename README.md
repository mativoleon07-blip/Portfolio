# Leon Mativo — Portfolio

A clean, modern dark-themed developer portfolio built with pure HTML, CSS, and JavaScript.

## Sections
- Hero / Intro
- About Me
- Skills & Technologies
- Projects
- Experience & Learning
- Contact

## How to use

1. Open `index.html` in any modern browser.
2. Or host it for free on **GitHub Pages**:
   - Push this folder to a repository
   - Go to Settings → Pages → Deploy from main branch
   - Your site will be live at `https://yourusername.github.io/repo-name`

## Customization

- Edit the text directly in `index.html`
- Change colors in the CSS variables at the top of `styles.css`
- Add more projects by copying a `.project-card` block

## Tech
- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript

Built for Leon Mativo.
